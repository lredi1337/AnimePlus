# Живые проверки

Настоящий Chrome в отдельном профиле, настоящие нажатия мышью, расширение из тех же файлов, что уйдут в ZIP для магазина. Основная сессия Chrome не затрагивается, вход в аккаунты не выполняется.

```bash
npm run stand -- smoke
```

Сценарии запускайте по одному: параллельные прогоны дают ложные сбои.

| Сценарий | Что проверяет | Нужен VPN |
|---|---|---|
| `smoke` | разрешения, защита входа, окно расширения, сайт, оболочка плеера | нет |
| `dock` | значок Anime+ на всех сайтах, вёрстка сайта не тронута; Топ поверх сайта, переход на тайтл, «Случайное аниме» (и на AnimeVost), перетаскивание, вкладка Топа с выбором сайта | нет |
| `synthetic` | страница тайтла из Shikimori на AnimeGO: сборка из шаблона, наведение, постер и кадры на весь экран, выбор сайта, связанные тайтлы | нет |
| `kodik` | плеер сайта уходит на Kodik и его нет в списке | да |
| `episodes` | смена серии в CVH, выбранная вручную серия на паузе | да |
| `quality` | качество CVH: готово при открытии, не мигает, применяется | да |
| `accuracy` | сравнение серий на настоящем звуке против меток Kodik; `--url` тайтл, `--count` число серий | нет |
| `follow` | опенинг позже первых 5 минут: обычный просмотр с автопропуском, песню находит анализ заранее впереди просмотра; `--url` тайтл, `--count` номер серии (по умолчанию 2 серия «Магической битвы»); `--speed 1.5` выключает анализ заранее и проверяет узнавание прослушиванием на этой скорости | нет |
| `skins` | тема выбирается на странице настроек, плеер перекрашивается без перезагрузки, кнопки не уходят под панель, затемнение кадра без шва у панели, превью на странице настроек открывает панели; снимки в `--out` | нет |
| `resume` | серия, начатая на одном сайте, продолжается на другом с той же секунды; после последней серии карточка с продолжением и переход на него; `--url` тайтл на первом сайте, `--sites` идентификаторы сайтов для второго, снимок карточки в `--out` | нет |
| `keys` | клавиши звука, громкости и скорости в кадре плеера, русская раскладка, нажатия на странице мимо плеера, стрелки страницы не трогают громкость, следующая серия с запомненной скоростью; `--url` тайтл | нет |
| `pick` | подбор аниме: значок в окне расширения, вопросы с выбором и «да / нет» без повторов, главный тайтл крупно с описанием и сайтами и семь постеров, кнопки на постере при наведении, «Не то» и «Видел», «Короче», панель тайтла поверх подборки (описание, кадры, сайты, Esc), прошлая подборка после перезагрузки, память об увиденном; снимки в `--out` | нет |
| `look` | оформление расширения: раздел «Оформление» в настройках, выбор стиля и темы нажатиями, открытое окно перекрашивается само; потом окно, «Случайное», Топ, расписание, подбор и настройки в каждом из шести стилей в светлой и тёмной теме (атрибуты, фон, color-scheme, своя раскладка стиля у «Случайного» и Топа, без сдвига вбок); снимки в `--out` | нет |
| `franchise` | «Порядок просмотра» на «Случайном»: тайтл с франшизой, блок приходит с карточкой и не сдвигает страницу, «вы здесь», «По выходу» и переход к тайтлу франшизы настоящими щелчками, блок в каждом стиле и теме; снимки в `--out` | нет |
| `perf` | нагрузка на процессор и память при просмотре и на паузе; `--no-extension` для сравнения, `--url` для другого тайтла | нет |

Параметры:

- `--proxy socks5://127.0.0.1:10808`: российский адрес. Happ: Settings → Inbounds, SOCKS5 на этом порту, профиль Global proxy On. Весь компьютер при этом через VPN не идёт.
- `--adblock <папка>`: распакованная копия блокировщика рядом с расширением. У зрителей он обычно стоит, и поведение плееров с ним другое. Копия AdGuard: `%LOCALAPPDATA%\Google\Chrome\User Data\Default\Extensions\bgnkhhnnamicmpeenaelnjfhikgbkllg\<версия>` без папки `_metadata`. В проект её не кладите.
- `--sites jutsu,club,online,tv`: только эти сайты.
- Переменные для `follow`: `STAND_DEBUG=1` печатает состояние распознавания и журнал запросов анализа заранее (время и ответ каждого куска), `STAND_STALL=1` подвешивает первый запрос четвёртого куска и всю вторую минуту, чтобы проверить повторы и пропуск минуты.
- Переменные для `resume`: `STAND_DEBUG=1` печатает состояние видео на каждом шаге, `STAND_SAME=1` проверяет место остановки на том же сайте после повторного открытия страницы.
- Переменная `CHROME_PATH`, если Chrome установлен не в обычную папку.

Коды выхода: 0 всё прошло, 1 есть сбои, 3 сбой самого стенда.

Что учитывать:

- Сайты и плееры меняются, а адреса тайтлов записаны в `run.js`. Сбой на одном тайтле сначала проверьте вручную: сайт мог его убрать.
- Страницы через прокси бывают медленными. Если сайт не догрузился за время ожидания, повторите прогон, прежде чем считать это ошибкой расширения.
- Смена серии и качества проверяется на CVH, поэтому `episodes` и `quality` без российского адреса не имеют смысла.
- Запуск видео с рекламой занимает до полутора минут.

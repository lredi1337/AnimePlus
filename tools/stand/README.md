# Живые проверки

Настоящий Chrome в отдельном профиле, настоящие нажатия мышью, расширение из тех же файлов, что уйдут в ZIP для магазина. Основная сессия Chrome не затрагивается, вход в аккаунты не выполняется.

```bash
npm run stand -- smoke
```

Сценарии запускайте по одному: параллельные прогоны дают ложные сбои.

| Сценарий | Что проверяет | Нужен VPN |
|---|---|---|
| `smoke` | разрешения, защита входа, окно расширения, сайт, оболочка плеера | нет |
| `dock` | значок Anime+ на всех сайтах, вёрстка сайта не тронута; Топ поверх сайта, переход на тайтл, «Случайное аниме» (и на AnimeVost), перетаскивание, вкладка Топа с выбором сайта | нет |
| `kodik` | плеер сайта уходит на Kodik и его нет в списке | да |
| `episodes` | смена серии в CVH, выбранная вручную серия на паузе | да |
| `quality` | качество CVH: готово при открытии, не мигает, применяется | да |
| `accuracy` | сравнение серий на настоящем звуке против меток Kodik; `--url` тайтл, `--count` число серий | нет |
| `skins` | тема выбирается на странице настроек, плеер перекрашивается без перезагрузки, кнопки не уходят под панель, затемнение кадра без шва у панели, превью на странице настроек открывает панели; снимки в `--out` | нет |
| `perf` | нагрузка на процессор и память при просмотре и на паузе; `--no-extension` для сравнения, `--url` для другого тайтла | нет |

Параметры:

- `--proxy socks5://127.0.0.1:10808`: российский адрес. Happ: Settings → Inbounds, SOCKS5 на этом порту, профиль Global proxy On. Весь компьютер при этом через VPN не идёт.
- `--adblock <папка>`: распакованная копия блокировщика рядом с расширением. У зрителей он обычно стоит, и поведение плееров с ним другое. Копия AdGuard: `%LOCALAPPDATA%\Google\Chrome\User Data\Default\Extensions\bgnkhhnnamicmpeenaelnjfhikgbkllg\<версия>` без папки `_metadata`. В проект её не кладите.
- `--sites jutsu,club,online,tv`: только эти сайты.
- Переменная `CHROME_PATH`, если Chrome установлен не в обычную папку.

Коды выхода: 0 всё прошло, 1 есть сбои, 3 сбой самого стенда.

Что учитывать:

- Сайты и плееры меняются, а адреса тайтлов записаны в `run.js`. Сбой на одном тайтле сначала проверьте вручную: сайт мог его убрать.
- Страницы через прокси бывают медленными. Если сайт не догрузился за время ожидания, повторите прогон, прежде чем считать это ошибкой расширения.
- Смена серии и качества проверяется на CVH, поэтому `episodes` и `quality` без российского адреса не имеют смысла.
- Запуск видео с рекламой занимает до полутора минут.

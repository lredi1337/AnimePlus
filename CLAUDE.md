# Anime+

Браузерное расширение Manifest V3 на чистом JS, без сборки. Отвечать пользователю по-русски.

## Команды

- `npm run check`: ESLint и все тесты. Запускать перед тем, как считать работу готовой.
- `node --test --test-force-exit tests/имя.test.js`: один файл тестов.

## Как устроен код

- `manifest.json` определяет, какие файлы и в каком порядке попадают на страницу, в каком мире (`MAIN` или `ISOLATED`) и в каких кадрах. Импортов между этими файлами нет, поэтому поиск по импортам не покажет связи.
- Части общаются сообщениями (`chrome.runtime`, `postMessage`). Переименовывая или меняя сообщение, ищи его строку по всему проекту.
- `modules/player/`: оболочка плеера и адаптеры плееров. `providers/`: сайты. `content-player.js`: код внутри кадров плеера. `background.js` и `modules/bg-*.js`: фоновая часть. `server/`: Cloudflare Worker, в расширение не входит.
- `AI_OVERVIEW.md` подробно описывает архитектуру, но написан для версии 10.1.1: сверяй его с кодом.

## Проверка изменений

- Исправляя ошибку, сначала напиши падающий тест, если её можно воспроизвести в `tests/`.
- Юнит-тесты не заменяют браузер. Поведение плеера, звука и пропуска проверяй настоящими нажатиями, с настройками обычного зрителя и по одному прогону за раз: параллельные прогоны дают ложные сбои.
- Прежде чем приписать результат своему коду, убедись в источнике: у плееров есть собственные метки и своё поведение.

## Выпуск

- Выпускать только по просьбе пользователя. Загрузку в Chrome Web Store пользователь делает сам.
- В ZIP для магазина не должны попадать `.claude/`, `CLAUDE.md`, `AI_OVERVIEW.md`, `assets/`, `tests/`, `tools/` и `server/`.

# Политика конфиденциальности для расширения Anime+

*Дата последнего обновления: 2 ноября 2026 г.*

Данная Политика конфиденциальности описывает порядок сбора, использования, обработки, хранения и передачи пользовательских данных в браузере при использовании расширения **Anime+** (версия 9.5.0 и новее) в соответствии с правилами Chrome Web Store Developer Program Policies.

---

## 1. Сбор данных (Data Collection)
Расширение **Anime+** **НЕ собирает, НЕ отслеживает и НЕ фиксирует** никакие персональные данные пользователей (Personal Identifiable Information — PII), включая:
* Имя, фамилию, адрес электронной почты или номер телефона;
* Данные учетных записей, пароли или токены авторизации;
* IP-адреса, геолокацию или данные устройства;
* Историю посещения сайтов, не относящихся к функционалу расширения;
* Финансовые или платежные данные.

Все действия пользователя и настройки функционала анализируются и применяются исключительно в локальной среде браузера.

---

## 2. Использование и обработка данных (Data Use & Processing)
Любая информация, обрабатываемая расширением (например, пользовательские переключатели, настройки видеоплеера, выбранный темп воспроизведения, горячие клавиши), используется **исключительно локально** для обеспечения работы функций расширения:
* Автоматический пропуск опенингов и эндингов в аниме-плеере;
* Включение/выключение полноэкранного режима плеера без рамок и режима «Картинка в картинке» (PiP);
* Автоматический выбор качества видео и автовоспроизведение следующей серии;
* Отображение дополнительной справочной информации об анонимных рейтингах и таймингах с открытых API.

Данные **НЕ используются** для профилирования, таргетинга рекламы, автоматизированного принятия решений или коммерческого анализа.

---

## 3. Хранение и защита данных (Data Storage & Security)
* **Место хранения:** Все пользовательские настройки (конфигурация плеера, горячие клавиши) и счётчик сэкономленного времени хранятся исключительно на устройстве пользователя с использованием стандартного локального API браузера — `chrome.storage.local`.
* **Shikimori OAuth-токен:** Если пользователь добровольно авторизуется через Shikimori, полученные `access_token` и `refresh_token` сохраняются локально в `chrome.storage.local` на устройстве пользователя. Токен используется для отправки запросов обновления прогресса от имени пользователя напрямую на `shikimori.io`.
* **Обмен кода авторизации:** Получение и обновление токенов выполняется через прокси-сервер разработчика `animeplus.ruscadred.workers.dev` (Cloudflare Worker), который добавляет секретный ключ приложения Shikimori. Через этот сервер проходят код авторизации и токены. Если сервер недоступен, запрос отправляется напрямую в Shikimori.
* **Срок хранения:** Настройки и токены хранятся до момента их сброса пользователем через интерфейс расширения (кнопка «Выйти») или до полного удаления расширения из браузера.
* **Анализ звука:** Для пропуска опенингов и эндингов расширение анализирует звук серии прямо на устройстве пользователя. Звук не записывается, не сохраняется и никуда не отправляется. Функцию можно отключить в настройках («Пропуск по звуку»).
* **Общая база таймингов:** Если расширение нашло время опенинга или эндинга по звуку, на сервер разработчика `animeplus-timings.ruscadred.workers.dev` (Cloudflare Worker) отправляются только сведения о серии: ID тайтла, номер серии, название озвучки, длина видео и найденное время. Они нужны, чтобы другие пользователи получали пропуск без анализа звука. IP-адрес не хранится: для отсева повторов от одного источника сохраняется необратимый хэш, отдельный для каждого тайтла. Отправка отключается вместе с функцией «Пропуск по звуку».
* **Безопасность:** За исключением описанных выше обмена кода авторизации и общей базы таймингов, данные не передаются на серверы разработчика и не дублируются в сторонних облачных хранилищах. Локальные данные защищены средствами изолированного окружения браузера.

## 4. Передача данных третьим лицам (Data Disclosure & Third Parties)
Расширение **НЕ передает, НЕ продает и НЕ сдает в аренду** данные пользователей третьим лицам или организациям.

Для выполнения основных функций расширения браузер пользователя выполняет прямые анонимные HTTP/HTTPS-запросы к публичным информационным ресурсам и API:
1. **Информационные аниме-базы и API таймингов:**
   * `shikimori.io`, `shikimori.one`, `shikimori.me`, `shikimori.org`
   * `api.aniskip.com`, `api.animethemes.moe`, `kitsu.io`, `kodikapi.com`, `myanimelist.net`
   * `cdn.jsdelivr.net`, `raw.githubusercontent.com`
   * *Цель:* получение публичных метаданных (название аниме, обложки, эпизоды, тайминги опенингов, отпечатки песен для распознавания).
2. **Аниме-порталы и плееры:**
   * `animego.me`, `animego.org`, `jut-su.net`, `ru.yummyani.me`, `old.yummyani.me`, `yummyanime.tv`, `animego.online`, `yammyanime.club`
   * Плееры `kodik.info`, `kodikplayer.com`, `aniboom.one` и их официальные веб-зеркала.
   * *Цель:* внедрение пользовательского интерфейса управления плеером на целевых страницах.

При таких запросах **НЕ передаются** никакие персональные или идентификационные данные пользователя. Передаются исключительно стандартные заголовки веб-запросов браузера, необходимые для получения публичного ответа от сервера.

Исключение: если пользователь авторизовался через Shikimori, запросы к Shikimori выполняются от имени его аккаунта и содержат токен доступа и данные о просмотренных сериях. Для поиска тайтла на других поддерживаемых сайтах этим сайтам передаётся название тайтла.

## 5. Использование разрешений (Permissions Justification)
Расширение запрашивает минимальный набор разрешений:
* **`storage`**: Сохранение настроек плеера и интерфейса локально в `chrome.storage.local`.
* **`activeTab`**: Отображение интерфейса управления (popup) при нажатии на иконку расширения.
* **`scripting`**: Внедрение сценариев управления плеером (пропуск опенингов, PiP) на поддерживаемых страницах.
* **`tabs`**: Определение открытого сайта для popup, перезагрузка вкладок при включении и выключении расширения, показ уведомлений о новых сериях на открытых вкладках.
* **`windows`**: Псевдополноэкранный режим плеера и отдельное окно уведомления о новой серии.
* **`notifications`**: Уведомления о выходе новых серий.
* **`alarms`**: Периодическая проверка новых серий.
* **`host_permissions`**: Доступ к поддерживаемым аниме-сайтам и публичным API для интеграции плеера и отображения таймингов.

---

## 6. Права пользователей и удаление данных
Пользователь имеет полный контроль над всеми данными расширения:
* Для сброса всех настроек достаточно очистить данные расширения в настройках браузера или нажать кнопку сброса в окне настроек расширения.
* Для полного удаления всех локальных данных достаточно удалить расширение **Anime+** из браузера.
